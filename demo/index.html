Weight stationary dot product accelerators that each fit one Tiny Tapeout tile on SkyWater sky130, with 4 bit weights kept on chip. Only 8 data pins feed the chip, so the one lever left is how many bits each pixel gets: fewer bits, more multiply accumulates per clock. The page runs each chip's exact integer arithmetic in your browser. An AI agent pipeline designed and verified them. None has been fabricated.

What is measured and what is not

Modeled: a digit you draw is classified by a JavaScript copy of the same integer math, not a simulation of the netlist. Not measured: silicon, and the RP2040 PIO host on a real demo board (co simulated at about 16 MHz chip clock).

Source, tests and CI: 4 bit, 2 bit and 1 bit, the model as logic · tt-fit · earlier versions: INT8 pin, UART · digits data: scikit-learn load_digits (UCI optdigits, CC BY 4.0) · Apache 2.0
